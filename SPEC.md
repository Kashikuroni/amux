# ТЗ: CLI менеджер сессий Claude Code на Rust

## Цель

Написать терминальный инструмент на Rust для управления несколькими сессиями Claude Code из одного места. Инструмент должен быть простым — без git worktree, без оркестрации агентов, только удобное управление tmux-сессиями.

---

## Стек

- **Язык:** Rust (edition 2021)
- **TUI:** `ratatui` + `crossterm`
- **Управление сессиями:** вызовы `tmux` через `std::process::Command`
- **Сериализация конфига:** `serde` + `serde_json` или `toml`

---


## Функциональные требования

### 1. Главный экран — список сессий

- Отображать список всех активных tmux-сессий созданных инструментом
- Для каждой сессии показывать:
  - название сессии (задаётся пользователем при создании)
  - рабочая директория
  - статус: `running` / `waiting` (есть ли активность в pane)
  - время создания
- Навигация стрелками ↑↓
- Выделенная строка подсвечивается

### 2. Превью вывода

- В правой или нижней панели показывать последние N строк вывода выбранной сессии
- Получать через `tmux capture-pane -t <session> -p`
- Обновлять автоматически раз в 1-2 секунды

### 3. Создание новой сессии

- Горячая клавиша: `n`
- Запросить у пользователя:
  1. Название сессии (строка)
  2. Рабочую директорию (путь, с поддержкой `~` и tab-completion если возможно)
- Запустить `tmux new-session -d -s <name> -c <dir> "claude"`
- Добавить сессию в список

### 4. Переключение на сессию

- Горячая клавиша: `Enter`
- Выполнить `tmux attach-session -t <name>`
- После detach (Ctrl+B, D) вернуться обратно в интерфейс менеджера

### 5. Удаление сессии

- Горячая клавиша: `d`
- Показать подтверждение: `Kill session "<name>"? (y/n)`
- При подтверждении: `tmux kill-session -t <name>`

### 6. Переименование сессии

- Горячая клавиша: `r`
- Inline редактирование названия в списке

### 7. Выход

- Горячая клавиша: `q`
- Сессии продолжают работать в фоне (только менеджер закрывается)

## Нефункциональные требования

- Инструмент запускается из **любой** директории — не привязывается к текущей
- Работает на macOS и Linux
- Не требует дополнительных зависимостей кроме `tmux` в PATH
- Бинарник называется `cm` (claude manager)
- При запуске если tmux не найден — выводить понятную ошибку

---

## Конфиг

Файл `~/.claude-manager/config.toml`:

```toml
# Команда для запуска агента (можно заменить на другой агент)
agent_command = "claude"

# Интервал обновления превью в миллисекундах
refresh_interval_ms = 1500
```

---

## Клавиши — итоговая таблица

| Клавиша | Действие |
|---------|----------|
| `↑` / `↓` | Навигация по списку |
| `Enter` | Подключиться к сессии |
| `n` | Создать новую сессию |
| `d` | Удалить сессию (с подтверждением) |
| `r` | Переименовать сессию |
| `q` | Выйти (сессии остаются в фоне) |
| `?` | Показать помощь |

## Что НЕ нужно реализовывать

- Git worktree интеграция
- Оркестрация агентов / межагентная коммуникация
- Синхронизация контекста между сессиями
- Поддержка нескольких агентов (только Claude Code)
- Авто-принятие команд (yolo режим)
- Web UI или GUI
